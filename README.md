# FitHub Admin API 🏋️‍♂️

Un sistem backend modern pentru gestionarea sălilor de fitness, construit cu .NET 8 și Docker.

## 🚀 Funcționalități
- **Clienți:** Înregistrare și validare unicitate email.
- **Abonamente:** Calcul automat preț/durată și prevenire suprapunere abonamente.
- **Acces:** Sistem de Check-In cu validare în timp real.
- **Auto-Migrare:** Baza de date se creează automat la pornire.

## 🛠️ Tehnologii
- .NET 8 (C#)
- Entity Framework Core
- SQLite
- Docker & Docker Compose

## 🐳 Cum să rulezi proiectul (Quick Start)

Ai nevoie doar de **Docker Desktop** instalat.

Clonează repository-ul:
   ```bash
   git clone <link-ul-tau-de-github>
```
Deschide terminalul în folderul proiectului și rulează
 ```bash
   docker-compose up --build
```
